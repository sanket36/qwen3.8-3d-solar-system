# Qwen 3.8 — Interactive 3D Solar System

An interactive single-file 3D Solar System generated by **Qwen 3.8 27B** as part of my local-LLM coding benchmark.

## Benchmark Conditions

* Model: Qwen 3.8 27B
* Model ran locally
* Task: Interactive 3D Solar System
* Output format: Single HTML file
* Framework: Three.js via CDN
* Generation: One prompt
* Human implementation during generation: None

## What Qwen Built

The generated experience includes:

* The Sun and all 8 planets
* Animated planetary orbits
* Relative orbital periods
* Procedural planet textures
* Custom animated Sun shader
* Saturn and Uranus particle rings
* OrbitControls camera navigation
* Smooth planet-focus camera transitions
* Interactive planet selection
* Orbital-speed control
* Light-intensity control
* Orbit-path toggle
* Hover tooltips
* Simulation telemetry
* Procedural starfield and nebula background

## Controls

* Left Mouse Button — Rotate camera
* Mouse Wheel — Zoom
* Right Mouse Button — Pan
* Click Planet — Focus / track planet
* Keys 1–8 — Focus planets
* Esc / 0 — Return to overview

## Benchmark Notes

The result is visually and technically impressive, but some requirements were interpreted rather than implemented literally.

### Known Limitations

1. Planet sizes are visually compressed rather than truly proportional.

2. Planet distances use a nonlinear scaling function so the whole Solar System remains usable on screen.

3. Orbital periods are represented, but planets travel on simplified circular orbits rather than full Keplerian elliptical trajectories.

4. Planet textures are procedurally generated rather than photorealistic astronomical textures.

5. Lighting is optimized for visibility rather than physically accurate inverse-square illumination.

## Runtime Dependencies

Although the application is contained in one HTML file, it loads:

* Three.js
* OrbitControls
* Google Fonts

from external CDNs.

An internet connection is therefore required when opening the hosted demo.
